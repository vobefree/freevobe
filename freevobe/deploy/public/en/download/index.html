If Windows warns about an unknown publisher

The Windows installer isn't code-signed yet, so SmartScreen shows "Windows protected your PC" and an unknown publisher — even though the file comes straight from this project's GitHub release. You can verify it yourself: the SHA256 checksum is listed next to the file in the release.

  1. 1. Click "More info" in the dialog — the "Run anyway" button only appears after that.
  2. 2. Click "Run anyway". The app then installs as usual.
  3. 3. Want to be sure first? Compare the file's SHA256 with the one in the release before you run it.

The phone app

Freevobe Mobile mirrors the desktop app: QR-pair once over your local network and then follow runs, diffs and approvals from the couch. Nothing leaves your Wi-Fi — the phone talks to the Freevobe agent running on your own machine.

  1. 1. Download the APK and open it. Android asks you to allow installs from this source — the file is not from Google Play.
  2. 2. Open the desktop app and show the pairing QR code. Point the phone at it.
  3. 3. Both devices need to be on the same network. Pairing works offline.

iOS builds are not published yet — they need a Mac and an Apple Developer account.

Freevobe Learn

Learn How to Vobe — as an app, not a page

1 file · ~0.34 MB

Write a world, have it checked and play it. The lessons show the code that built the map. The app is a single HTML file: download it, open it and play — no server, no account, no model and no connection. Progress is saved in your own browser.

  1. 1. Download freevobe-learn.html from the release.
  2. 2. Open the file in any browser — it works from the folder you saved it in, even offline.
  3. 3. Move it to your desktop if you want it as its own app. It stays until you remove it.

Before you install

  • Ollama
    Running locally, with at least one model pulled
  • Disk
    ~120 MB for the app, plus the space your models need
  • Platforms
    Windows 10+, macOS 12+ (Apple Silicon or Intel), Linux (AppImage, x86-64)
  • Phone
    Android 8+ can install the APK directly. iOS needs a Mac and an Apple account.

Where the files live

Every build is attached to a tag on vobefree/freevobe. Nothing is served from this site, and the badge above shows the newest tag as soon as one exists.
