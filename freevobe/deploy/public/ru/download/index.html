Если Windows предупреждает о неизвестном издателе

Установщик для Windows пока не подписан, поэтому SmartScreen показывает «Windows защитила ваш компьютер» и неизвестного издателя — хотя файл взят прямо из релиза проекта на GitHub. Это можно проверить: контрольная сумма SHA256 указана рядом с файлом в релизе.

  1. 1. Нажмите «Подробнее» в окне — кнопка «Выполнить в любом случае» появляется только после этого.
  2. 2. Нажмите «Выполнить в любом случае». Дальше приложение установится как обычно.
  3. 3. Хотите сначала убедиться? Сравните SHA256 файла с суммой в релизе, прежде чем запускать его.

Приложение для телефона

Freevobe Mobile повторяет десктопное приложение: сопрягите один раз по QR-коду в локальной сети и следите за запусками, diff и подтверждениями с дивана. Ничего не покидает ваш Wi-Fi — телефон общается с агентом Freevobe на вашей машине.

  1. 1. Скачайте APK и откройте его. Android спросит разрешение на установку из этого источника — файл не из Google Play.
  2. 2. Откройте десктопное приложение и покажите QR-код сопряжения. Наведите на него телефон.
  3. 3. Оба устройства должны быть в одной сети. Сопряжение работает офлайн.

Сборки для iOS пока не публикуются — для них нужны Mac и аккаунт Apple Developer.

Learn How to Vobe — приложение, а не страница

1 файл · ~0,34 МБ

Опишите мир, проверьте его и сыграйте. Уроки показывают код, который построил карту. Приложение — один HTML-файл: скачайте, откройте и играйте. Без сервера, аккаунта, модели и подключения. Прогресс сохраняется в вашем браузере.

Перед установкой

  • Ollama
    Запущена локально, хотя бы одна модель скачана
  • Диск
    ~120 МБ для приложения плюс место для ваших моделей
  • Платформы
    Windows 10+, macOS 12+ (Apple Silicon или Intel), Linux (AppImage, x86-64)
  • Телефон
    Android 8+ может установить APK напрямую. Для iOS нужны Mac и аккаунт Apple.
