下載 Freevobe

選擇你的平台——下面的按鈕已經知道是哪個。Freevobe 可離線執行，並與你自己機器上的 Ollama 通訊。

Freevobe 透過 GitHub Releases 發佈。

檔案尚未程式碼簽章——請對照發佈頁的 SHA256 校驗值。原始碼使用 MIT 授權。

如果 Windows 提示未知發佈者

Windows 安裝檔尚未程式碼簽章，因此 SmartScreen 會顯示「Windows 已保護您的電腦」與未知發佈者——儘管檔案直接來自本專案的 GitHub 發佈頁。你可以自行核驗：發佈頁上該檔案旁列出了 SHA256 校驗值。

  1. 1. 在對話方塊中點「更多資訊」——「仍要執行」按鈕要在此之後才會出現。
  2. 2. 點「仍要執行」，接著應用程式會照常安裝。
  3. 3. 想先確認？執行前把檔案的 SHA256 與發佈頁上的校驗值比對一下。

手機應用

Freevobe Mobile 與桌面應用同步：在區域網路用 QR 碼配對一次，就可以在沙發上查看執行、diff 與核准。任何內容都不會離開你的 Wi-Fi——手機與你機器上執行的 Freevobe 代理通訊。

  1. 1. 下載 APK 並開啟。Android 會詢問是否允許從此來源安裝——這個檔案不是來自 Google Play。
  2. 2. 開啟桌面應用並顯示配對 QR 碼，把手機對準它。
  3. 3. 兩台裝置必須在同一個網路。配對可以離線完成。

iOS 版本尚未發佈——需要 Mac 與 Apple Developer 帳號。
