運作方式

三個步驟完成第一次發佈。

1

下載 Freevobe

取得 Windows、macOS 或 Linux 原生應用。不用安裝其他東西——代理已隨附。

2

連接 Ollama

Freevobe 會找到 localhost:11434，列出你的模型，並標示哪些支援工具呼叫。

3

開始 vobe

描述你想要的应用。審查每個 diff、核准指令，讓代理提交。

  1. 01安裝

    適用你系統的原生應用

  2. 02連接 Ollama

    一鍵連到 localhost:11434

  3. 03選擇模型

    任何已下載的模型

  4. 04提示

    描述要打造什麼

  5. 05審查 diff

    核准每一處變更

  6. 06發佈

    提交並執行測試

沒有廣告

Freevobe 不含廣告版位、廣告腳本與廣告網路。應用裡沒有任何東西在販售。

不透過 Freevobe 收錢

應用沒有付款、沒有帳號、沒有支付服務商。每個連結都開啟機構自己的頁面。

預設關閉

聊天中的提醒是自願開啟的，顯示在獨立區塊，絕不進入代理的上下文。

紀錄只留在本機

如果你記錄了一筆捐款，它會標示為自行申報，只保存在你的本機資料庫。

這份名單是編輯性質的，連結指向各機構自己的首頁而不是結帳頁，這樣付款流程改變也不會變成空頭承諾。Freevobe 與這裡列出的任何機構都沒有合作、佣金或推薦協議。完整說明見 docs/gives-back.md.

隱私

你的程式碼始終屬於你。

Freevobe 預設在本機執行。在你自己的機器上連接 Ollama，讓專案、提示與檔案保持私密。

  • 沒有帳號，也不需要登入。
  • 沒有離開應用的遙測。
  • 每次寫入前都有 diff 與核准。
