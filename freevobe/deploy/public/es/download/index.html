Descarga Freevobe

Elige tu plataforma: el botón de abajo ya la conoce. Freevobe funciona sin conexión y habla con la instalación de Ollama en tu propia máquina.

Freevobe se distribuye a través de GitHub Releases.

Los archivos aún no están firmados: comprueba el checksum SHA256 en la release. El código fuente tiene licencia MIT.

Si Windows avisa de un editor desconocido

El instalador de Windows aún no está firmado, así que SmartScreen muestra «Windows protegió tu PC» y un editor desconocido, aunque el archivo venga directamente de la release de GitHub del proyecto. Puedes comprobarlo: el checksum SHA256 aparece junto al archivo en la release.

  1. 1. Haz clic en «Más información» en el diálogo: el botón «Ejecutar de todos modos» solo aparece después.
  2. 2. Haz clic en «Ejecutar de todos modos». La app se instala como siempre.
  3. 3. ¿Prefieres asegurarte antes? Compara el SHA256 del archivo con el de la release antes de ejecutarlo.

La app del teléfono

Freevobe Mobile refleja la app de escritorio: empareja una vez con el código QR en tu red local y sigue ejecuciones, diffs y aprobaciones desde el sofá. Nada sale de tu Wi-Fi: el teléfono habla con el agente Freevobe que corre en tu propia máquina.

  1. 1. Descarga el APK y ábrelo. Android te pedirá permitir instalaciones de esta fuente: el archivo no viene de Google Play.
  2. 2. Abre la app de escritorio y muestra el código QR de emparejamiento. Apunta el teléfono hacia él.
  3. 3. Ambos dispositivos deben estar en la misma red. El emparejamiento funciona sin conexión.

Las compilaciones para iOS aún no se publican: requieren un Mac y una cuenta de Apple Developer.

Freevobe Learn

Learn How to Vobe: como app, no como página

1 archivo · ~0,34 MB

Escribe un mundo, haz que se compruebe y juégalo. Las lecciones muestran el código que construyó el mapa. La app es un único archivo HTML: descárgalo, ábrelo y juega. Sin servidor, sin cuenta, sin modelo y sin conexión. El progreso se guarda en tu propio navegador.

  1. 1. Descarga freevobe-learn.html desde la versión.
  2. 2. Abre el archivo en cualquier navegador: funciona desde la carpeta donde lo guardaste, incluso sin red.
  3. 3. Muévelo al escritorio si lo quieres como app propia. Se queda hasta que lo elimines tú.

Antes de instalar

  • Ollama
    En ejecución local, con al menos un modelo descargado
  • Disco
    ~120 MB para la app, más el espacio que necesiten tus modelos
  • Plataformas
    Windows 10+, macOS 12+ (Apple Silicon o Intel), Linux (AppImage, x86-64)
  • Teléfono
    Android 8+ puede instalar el APK directamente. iOS requiere un Mac y una cuenta de Apple.
