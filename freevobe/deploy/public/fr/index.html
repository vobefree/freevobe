Limites d'usage

Exécutez en local avec Ollama.

Votre GPU fait le travail. Pas de limite de débit, pas de plafond hebdomadaire et pas d'attente d'une remise à zéro à minuit.

Coûts d'API

Aucune facturation au token.

Un modèle local, des prompts illimités. Le seul coût est l'électricité que vous payez déjà.

Confidentialité dans le cloud

Votre code reste sur votre machine.

Les fichiers, les prompts et les diffs ne quittent jamais votre ordinateur, sauf si vous connectez vous-même un modèle cloud.

Comment ça marche

Trois étapes jusqu'à votre première livraison.

1

Téléchargez Freevobe

Prenez l'app native pour Windows, macOS ou Linux. Rien d'autre à installer : l'agent est inclus.

2

Connectez Ollama

Freevobe trouve localhost:11434, liste vos modèles et indique ceux qui gèrent les appels d'outils.

3

Commencez à vober

Décrivez l'app que vous voulez. Relisez chaque diff, approuvez les commandes et laissez l'agent commiter.

Skills et modèles

Apprenez à Freevobe comment vous construisez.

Les skills sont de simples fichiers Markdown avec un frontmatter YAML. Déposez-les dans votre projet et l'agent les prend en compte : aucun plugin, aucune recompilation.

react-component.mdskill

---

name: react-component

description: “Génère un composant typé avec tests et stories.”

tools: [read, edit, terminal]

---

export function {{name}}(props: {{name}}Props) {}

Composant React

nextjs-page.mdskill

---

name: nextjs-page

description: “Page App Router avec métadonnées et état de chargement.”

tools: [read, edit, terminal]

---

export default async function Page() {}

Page Next.js

api-endpoint.mdskill

---

name: api-endpoint

description: “Route handler avec validation et réponses typées.”

tools: [read, edit, terminal]

---

export async function POST(request: Request) {}

Point d'API

name: bug-fix

description: “Reproduire, isoler, corriger, et le prouver par un test.”

tools: [read, edit, terminal]

Correction de bug

Aucune publicité

Freevobe est livré sans encart, sans script publicitaire et sans régie. Rien dans l'app n'est à vendre.

Aucun argent via Freevobe

L'app n'a ni paiement, ni compte, ni prestataire de paiement. Chaque lien ouvre la page de l'organisation elle-même.

Désactivé par défaut

Le rappel dans le chat est facultatif, apparaît dans son propre bloc et ne touche jamais le contexte de l'agent.

Votre journal reste local

Si vous enregistrez un don, il est marqué comme déclaré par vous et stocké uniquement dans votre base de données locale.

Le catalogue est éditorial et les liens pointent vers la page d'accueil de chaque organisation plutôt que vers un paiement, afin qu'un changement de parcours de paiement ne transforme jamais une promesse en rupture. Freevobe n'a aucun partenariat, commission ou accord de recommandation avec les organisations listées ici. Lire la description complète dans docs/gives-back.md.

Confidentialité

Freevobe fonctionne en local par défaut. Connectez Ollama sur votre propre machine et gardez vos projets, prompts et fichiers privés.

  • Aucune télémétrie ne quitte l'app.
  • Diff et approbation avant chaque écriture.
