Télécharger Freevobe

Choisissez votre plateforme : le bouton ci-dessous la connaît déjà. Freevobe fonctionne hors ligne et parle à l'installation Ollama de votre machine.

Freevobe est distribué via GitHub Releases.

Les fichiers ne sont pas encore signés — vérifiez l'empreinte SHA256 dans la release. Le code source est sous licence MIT.

Si Windows signale un éditeur inconnu

L'installateur Windows n'est pas encore signé, donc SmartScreen affiche « Windows a protégé votre PC » et un éditeur inconnu — alors que le fichier vient directement de la release GitHub du projet. Vous pouvez le vérifier : l'empreinte SHA256 figure à côté du fichier dans la release.

  1. 1. Cliquez sur « Informations complémentaires » dans la fenêtre : le bouton « Exécuter quand même » n'apparaît qu'après.
  2. 2. Cliquez sur « Exécuter quand même ». L'application s'installe ensuite normalement.
  3. 3. Vous préférez vérifier avant ? Comparez l'empreinte SHA256 du fichier avec celle de la release avant de le lancer.

L'app du téléphone

Freevobe Mobile reflète l'app de bureau : associez une fois avec le QR code sur votre réseau local, puis suivez les exécutions, diffs et approbations depuis le canapé. Rien ne sort de votre Wi-Fi : le téléphone parle à l'agent Freevobe qui tourne sur votre machine.

  1. 1. Téléchargez l'APK et ouvrez-le. Android demande d'autoriser les installations depuis cette source : le fichier ne vient pas de Google Play.
  2. 2. Ouvrez l'app de bureau et affichez le QR code d'association. Pointez le téléphone dessus.
  3. 3. Les deux appareils doivent être sur le même réseau. L'association fonctionne hors ligne.

Les builds iOS ne sont pas encore publiés : ils demandent un Mac et un compte Apple Developer.

Freevobe Learn

Learn How to Vobe : une app, pas une page

1 fichier · ~0,34 Mo

Écrivez un monde, faites-le vérifier et jouez-y. Les leçons montrent le code qui a construit la carte. L'app est un seul fichier HTML : téléchargez-le, ouvrez-le et jouez. Aucun serveur, aucun compte, aucun modèle et aucune connexion. La progression est enregistrée dans votre navigateur.

  1. 1. Téléchargez freevobe-learn.html depuis la version.
  2. 2. Ouvrez le fichier dans n'importe quel navigateur : il fonctionne depuis le dossier où vous l'avez enregistré, même hors ligne.
  3. 3. Déplacez-le sur le bureau si vous voulez en faire une app à part. Il reste jusqu'à ce que vous le supprimiez.

Avant d'installer

  • Ollama
    En cours d'exécution en local, avec au moins un modèle téléchargé
  • Disque
    ~120 Mo pour l'app, plus l'espace nécessaire à vos modèles
  • Plateformes
    Windows 10+, macOS 12+ (Apple Silicon ou Intel), Linux (AppImage, x86-64)
  • Téléphone
    Android 8+ peut installer l'APK directement. iOS nécessite un Mac et un compte Apple.

Où se trouvent les fichiers
